# HashMap Pokédex

Aplicación Angular con navegación mediante `HashLocationStrategy` y una vista de
Pokédex alimentada por [PokéAPI](https://pokeapi.co/).

## Desarrollo

```bash
npm ci
npm start
```

La aplicación tiene estas rutas:

- `/#/` - Inicio
- `/#/pokemon` - Lista de Pokémon
- `/#/about` - Información del proyecto

## Validación

```bash
npm test
npm run build
```
